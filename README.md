# Level Up · Digital Commerce FY26

Interactive review for 23.11.2026. Everything (images, fonts, icons) is inside `index.html`, so it needs no build step.

## Publish on GitHub Pages
1. Create a repository (private is fine if your plan supports private Pages) and upload `index.html`, `.nojekyll` and this README to the root.
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. After about a minute the site is live at `https://<user>.github.io/<repo>/`.
